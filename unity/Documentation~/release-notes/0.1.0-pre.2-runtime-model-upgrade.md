# 0.1.0-pre.2: Runtime model dependency upgrade

## Summary

The Unity SDK now ships the pinned `Voxta.Model` 1.11.0-beta.1 runtime
assembly, SignalR 10.0.12, and `System.Text.Json` 10.0.12 as one verified
managed dependency closure. Unity consumers do not restore NuGet packages:
the required 24 managed assemblies are vendored in
`Runtime/Plugins/ThirdParty`.

The closure is enabled for the Unity Editor and standalone Windows, Linux, and
macOS. It replaces the former 27-DLL closure: the new managed assets total
2,768,792 bytes, an increase of 307,160 bytes.

## Public API migration

This prerelease removes the generated
`Voxta.Unity.Protocol.Generated` type identity from the runtime API. SDK
message types now come from `Voxta.Model.WebsocketMessages.ClientMessages`,
`Voxta.Model.WebsocketMessages.ServerMessages`, and `Voxta.Model.Shared`.
Applications that expose these types in source, callbacks, generic arguments,
or serialized UnityEvents must update their references; UnityEvent bindings
using the prior generated types must be selected again.

`VoxtaJsonSerializer.CreateSerializeOptions()` is now the required serializer
configuration. It writes protocol enums as strings, and app-trigger arguments
are model `object?[]` values whose object slots deserialize as `JsonElement`.
See [`runtime-model-public-api-migration.md`](../runtime-model-public-api-migration.md)
for the complete type mapping and migration steps.

## Upgrade guidance

Do not add `Voxta.Model` or SignalR packages to a Unity project's NuGet or UPM
configuration. The SDK validates the shipped closure in CI; a newer NuGet
model release is an intentional dependency update, not an automatic runtime
upgrade.
