# 0.1.0-beta.2: Unity 6.5 compatibility

## Summary

The package now imports without errors in Unity 6.5 and later. Those editors
compile scripts against their own `System.Text.Json` 8.0.0.0, so the bundled
closure moves to SignalR client 8.0.32 and `System.Text.Json` 8.0.6, and
`Voxta.Model` is built against `System.Text.Json` 8. On Unity 6.5+, the
package uses the editor's copies of the assemblies it supplies. See
[`third-party-dependencies.md`](../third-party-dependencies.md) for the full
closure.

## Breaking changes

- The `Voxta.Unity` namespaces are now `Voxta.GameEngine` and
  `Voxta.GameEngine.Transport`, and the assemblies are named
  `Voxta.GameEngine.*`. Update `using` directives and any assembly definition
  that references `Voxta.Unity.Runtime`.
- The SDK assemblies compile only for the Editor and Windows x64, macOS, and
  Linux x64 standalone players.
- The device-flow token is saved under the PlayerPrefs key
  `Voxta.GameEngine.AccessToken`, so existing installs authorize once more.

## Upgrade guidance

Delete any previously imported copy of the Basic Chat Integration sample under
`Assets/Samples/Voxta Game Engine SDK` and import it again; the old copy uses
the previous namespace and will not compile.
